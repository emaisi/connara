# Console screenshots / 后台截图

These screenshots were captured from the running Connara administration console (then named APIHub) on 2026-09-17 after the sidebar was reorganized into six main entries. They show actual built-in catalog data, with no configured integrations or generated business activity. The only displayed account is the local default administrator; no passwords, tokens, or credential forms are exposed.
